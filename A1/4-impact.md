# Impact Statement



This program replaces guesswork about work hours with real data, and that changes things for the workers, for management, and for the people who used to track time by hand.

For the Floor Staff, time tracking gets simple and hard to mess up. When they punch in to a new job, the system punches them out of the old one, and anyone who forgets to punch out is closed off at 5:30 PM. So every work event has a clear start and end. Workers can also pull up the Jobs Completed Report for any date range and see exactly how many hours they worked. If a paycheque looks wrong, they have their own record to check it against.

For management, every job now comes with the real minutes each employee spent on it. When a customer calls about a new part, ABC can quote the price and delivery date based on how long similar jobs actually took, not on a rough estimate.

There is a downside. Whoever used to collect time cards and add up hours by hand will lose most of that work, and if systems like this spread across manufacturing, that kind of job will shrink. But the time freed up can go to work that actually needs a person, like planning or quality checks, so overall the company gets more done with the same people.
